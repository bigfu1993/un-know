# 佚名用户端运行部署文档

> 适用目录：`D:\code\un-know\client`  
> 当前代码覆盖：`apps/h5` React/Vite H5、`apps/miniapp` Taro 微信小程序、共享 `packages`  
> 目标发布平台：H5、微信小程序、原生 App

## 1. 当前项目结构

```text
client/
  apps/
    h5/           # React + Vite H5 用户端
    miniapp/      # Taro + React 微信小程序
  packages/
    domain/       # 角色、商品、订单、钱包、兼职、委托/狩猎、家教等类型
    api-client/   # 用户端 API 调用封装
    hooks/        # TanStack Query hooks
    validators/   # 表单校验
    ui-tokens/    # UI token
```

## 2. 环境要求

- Node.js：建议 `20 LTS` 或更高
- npm：随 Node 安装
- 后端服务：默认 `http://127.0.0.1:8080`

H5 修改后端地址：

```powershell
$env:VITE_API_BASE_URL="http://127.0.0.1:8080"
```

微信小程序修改后端地址：

```powershell
$env:TARO_APP_API_BASE_URL="https://api.example.com"
```

## 4. 真实接口联调

前端 API 客户端已经移除本地假数据回退。后端未启动、数据库不可用或接口异常时，页面会展示真实接口错误，不会生成本地假数据。

联调顺序：

1. 启动云数据库 SSH 隧道。
2. 启动 `server` 后端服务。
3. 启动 `client` H5。
4. 打开 `http://127.0.0.1:5174`。
5. 使用手机号和验证码登录，当前种子数据验证码为 `123456`。

验证接口：


## 6. H5 部署

生产构建：

```powershell
cd D:\code\un-know\client
$env:VITE_API_BASE_URL="https://api.example.com"
npm ci
npm run build:h5
```

部署目录：

```text
client/apps/h5/dist
```

Nginx 示例：

```nginx
server {
  listen 80;
  server_name h5.example.com;

  root /var/www/unknown-h5;
  index index.html;

  location / {
    try_files $uri $uri/ /index.html;
  }

  location /assets/ {
    expires 30d;
    add_header Cache-Control "public, immutable";
  }
}
```

## 7. 微信小程序部署

正式发布流程：

1. 在 `client` 目录执行 `npm run build:miniapp`。
2. 使用微信开发者工具打开 `D:\code\un-know\client\apps\miniapp`。
3. 在微信公众平台配置合法域名，至少包含后端 API 域名。
4. 本地预览无误后上传代码并提交体验版。
5. 体验版验证通过后提交审核。
6. 审核通过后发布正式版。

## 9. 常见问题

### 页面能打开但显示接口错误

说明 H5 已经连接真实 API，但后端、SSH 隧道或数据库连接异常。先检查：

```text
http://127.0.0.1:8080/actuator/health
```

### 修改后端地址不生效

环境变量会在启动或构建时注入。修改 `VITE_API_BASE_URL` 后需要重启 Vite；修改 `TARO_APP_API_BASE_URL` 后需要重新执行 Taro watch 或构建。

### 端口冲突

- H5 默认端口：`5174`
- 后端默认端口：`8080`
- PostgreSQL SSH 隧道端口：`15432`

如需修改 H5 端口，调整 `apps/h5/vite.config.ts`。
