> 适用目录：`D:\code\un-know\client`  
> 当前代码覆盖：`apps/h5` React/Vite H5、`apps/miniapp` Taro 微信小程序、共享 `packages`

## 1. 当前项目结构

```text
client/
  apps/
    h5/           # React + Vite H5 用户端
    miniapp/      # Taro + React 微信小程序
```

## 2. 环境要求

- Node.js：建议 `20 LTS` 或更高
- npm：随 Node 安装
- 后端服务：默认 `http://127.0.0.1:9988`

H5 修改后端地址：

```powershell
$env:VITE_API_BASE_URL="http://127.0.0.1:9988"
```

微信小程序修改后端地址：



## 4. 真实接口联调

前端 API 客户端已经移除本地假数据回退。后端未启动、数据库不可用或接口异常时，页面会展示真实接口错误，不会生成本地假数据。

联调顺序：

1. 启动云数据库 SSH 隧道。
2. 启动 `server` 后端服务。
3. 启动 `client` H5。
4. 打开 `http://127.0.0.1:8899`。
5. 使用手机号和验证码登录，当前本地联调验证码为 `000000`。

Windows PowerShell 启动 SSH 隧道：

```powershell
$TunnelReady = Test-NetConnection 127.0.0.1 -Port 15432 -InformationLevel Quiet
if (-not $TunnelReady) {
  $KeyPath = "$env:USERPROFILE\.ssh\unknow\bigfu.m2pro.mac.home.pem"
  if (-not (Test-Path -LiteralPath $KeyPath)) {
    throw "未找到 SSH 密钥：$KeyPath。请提供明确密钥路径，或先手动建立 127.0.0.1:15432 隧道。"
  }
  ssh.exe -i $KeyPath -o ExitOnForwardFailure=yes -o ServerAliveInterval=60 -o ServerAliveCountMax=3 -N -L 15432:127.0.0.1:5432 root@8.153.110.192
}
```

macOS/Linux 启动 SSH 隧道：

```bash
nc -zv 127.0.0.1 15432 || ssh -f -i ~/.ssh/unknow/bigfu.m2pro.mac.home.pem -o ExitOnForwardFailure=yes -o ServerAliveInterval=60 -o ServerAliveCountMax=3 -N -L 15432:127.0.0.1:5432 root@8.153.110.192
```

Windows PowerShell 启动后端：

```powershell
cd "$RepoRoot\server"
Get-Content -LiteralPath .env.prod.local | ForEach-Object {
  if ($_ -and $_ -notmatch "^\s*#") {
    $name, $value = $_ -split "=", 2
    if ($name -and $value) {
      Set-Item -Path "Env:$name" -Value $value
    }
  }
}
mvn.cmd spring-boot:run
```

macOS/Linux 启动后端：

```bash
cd "$REPO_ROOT/server"
set -a
source .env.prod.local
set +a
mvn spring-boot:run
```

## 9. 常见问题

### 页面能打开但显示接口错误

说明 H5 已经连接真实 API，但后端、SSH 隧道或数据库连接异常。先检查：

```text
http://127.0.0.1:9988/actuator/health
```

### 修改后端地址不生效

环境变量会在启动或构建时注入。修改 `VITE_API_BASE_URL` 后需要重启 Vite；修改 `TARO_APP_API_BASE_URL` 后需要重新执行 Taro watch 或构建。

### 端口冲突

- H5 默认端口：`8899`
- 后端默认端口：`9988`
- PostgreSQL SSH 隧道端口：`15432`

如需修改 H5 端口，调整 `apps/h5/vite.config.ts`。
