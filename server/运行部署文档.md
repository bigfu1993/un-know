# 佚名后端运行部署文档

> 适用目录：`D:\code\un-know\server`  
> 技术栈：`Java 21 + Spring Boot 3.x + Maven + PostgreSQL + Flyway`

## 1. 环境要求

- JDK：`21`
- Maven：`3.9+`
- 默认端口：`8080`
- 数据库：PostgreSQL


## 2. 本地真实数据库联调

本地后端不再使用本地假数据。启动前需要先连接云服务器 PostgreSQL。

启动 SSH 隧道：

```powershell
ssh -i C:\Users\Administrator\.ssh\id_rsa -N -L 15432:127.0.0.1:5432 root@8.153.110.192
```

另开终端启动后端：

```powershell
cd D:\code\un-know\server

$env:SPRING_PROFILES_ACTIVE="prod"
$env:SPRING_DATASOURCE_URL="jdbc:postgresql://127.0.0.1:15432/unknown_platform"
$env:SPRING_DATASOURCE_USERNAME="unknown_app"
$env:SPRING_DATASOURCE_PASSWORD="数据库账号密码"

mvn spring-boot:run
```

如果需要后台启动，日志统一写入项目根目录的 `log/server`：

```powershell
cd D:\code\un-know\server

Start-Process -FilePath "mvn" `
  -ArgumentList @("spring-boot:run") `
  -RedirectStandardOutput "..\log\server\spring-boot-realdb.log" `
  -RedirectStandardError "..\log\server\spring-boot-realdb.err.log" `
  -WindowStyle Hidden
```

## 6. Linux systemd 部署示例

建议目录：

```text
/opt/unknown/server/unknown-platform-server.jar
/opt/unknown/server/logs/
```

`/etc/systemd/system/unknown-server.service`：

```ini
[Unit]
Description=Unknown Platform Server
After=network.target

[Service]
User=unknown
WorkingDirectory=/opt/unknown/server
Environment=SPRING_PROFILES_ACTIVE=prod
Environment=SPRING_DATASOURCE_URL=jdbc:postgresql://127.0.0.1:5432/unknown_platform
Environment=SPRING_DATASOURCE_USERNAME=unknown_app
Environment=SPRING_DATASOURCE_PASSWORD=数据库账号密码
ExecStart=/usr/bin/java -jar /opt/unknown/server/unknown-platform-server.jar
SuccessExitStatus=143
Restart=always
RestartSec=5
StandardOutput=append:/opt/unknown/server/logs/server.log
StandardError=append:/opt/unknown/server/logs/server.err.log

[Install]
WantedBy=multi-user.target
```

启动：

```bash
sudo systemctl daemon-reload
sudo systemctl enable unknown-server
sudo systemctl start unknown-server
sudo systemctl status unknown-server
```

## 7. Nginx 反向代理示例

```nginx
server {
  listen 80;
  server_name api.example.com;

  location / {
    proxy_pass http://127.0.0.1:8080;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
  }
}
```

## 8. 生产配置建议

生产环境必须通过环境变量或安全配置中心提供敏感信息：

```text
SPRING_PROFILES_ACTIVE=prod
SERVER_PORT=8080
SPRING_DATASOURCE_URL=jdbc:postgresql://127.0.0.1:5432/unknown_platform
SPRING_DATASOURCE_USERNAME=unknown_app
SPRING_DATASOURCE_PASSWORD=********
WECHAT_MINIAPP_APP_ID=********
WECHAT_MINIAPP_APP_SECRET=********
```

后续正式上线前还需要补齐：

- JWT 密钥和刷新机制
- CORS 域名白名单
- 数据库连接池参数
- 日志落盘与轮转
- 支付回调验签
- 对象存储访问密钥
- 管理端权限和审计
