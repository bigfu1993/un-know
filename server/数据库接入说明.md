# 数据库接入说明

当前后端已切换为真实 PostgreSQL 数据库链路。用户端登录、首页、商品、订单、钱包、兼职、委托/狩猎、家教等接口均从数据库读取或写入，不再使用本地假数据兜底。

## 当前约定

- 默认启动 profile：`prod`
- 本地开发数据库连接：通过 SSH 隧道访问云服务器 PostgreSQL
- 云服务器：`8.153.110.192`
- 本地隧道地址：`127.0.0.1:15432`
- 服务端部署在云服务器时的数据库地址：`127.0.0.1:5432`
- 数据库名：`unknown_platform`
- 数据库账号：`unknown_app`
- 数据库密码：通过本地 `server/.env.prod.local` 或环境变量提供，不写入代码仓库

## 本地真实联调流程

先启动 SSH 隧道：

```powershell
ssh -i C:\Users\Administrator\.ssh\id_rsa -N -L 15432:127.0.0.1:5432 root@8.153.110.192
```

再启动后端：

```powershell
cd D:\code\un-know\server

$env:SPRING_PROFILES_ACTIVE="prod"
$env:SPRING_DATASOURCE_URL="jdbc:postgresql://127.0.0.1:15432/unknown_platform"
$env:SPRING_DATASOURCE_USERNAME="unknown_app"
$env:SPRING_DATASOURCE_PASSWORD="数据库账号密码"

mvn spring-boot:run
```

也可以把同样的配置放入本地忽略文件 `server/.env.prod.local`，启动前加载该文件中的环境变量。

## 云服务器数据库状态

云服务器已安装 PostgreSQL，并创建：

```sql
CREATE DATABASE unknown_platform;
CREATE USER unknown_app WITH PASSWORD '由环境变量保存';
```

当前推荐本地开发继续走 SSH 隧道。公网直连 `8.153.110.192:5432` 需要额外放行阿里云 ECS 安全组、本机公网 IP、PostgreSQL 监听地址与 `pg_hba.conf`，第一阶段不建议直接暴露数据库端口。

## 数据库版本管理

项目使用 Flyway 管理数据库结构：

```text
server/src/main/resources/db/migration
```

当前迁移：

```text
V1__init_platform_schema.sql
V2__real_client_data.sql
```

后端启动 `prod` profile 时会自动校验并执行未应用的迁移脚本。
