# 数据库接入说明

当前后端已切换为真实 PostgreSQL 数据库链路。用户端登录、首页、商品、订单、钱包、兼职、委托/狩猎、家教等接口均从数据库读取或写入，不再使用本地假数据兜底。

## 当前约定

- 默认启动 profile：`prod`
- 本地开发数据库连接：通过 SSH 隧道访问云服务器 PostgreSQL
- 云服务器：`8.153.110.192`
- 本地隧道地址：`127.0.0.1:15432`
- 服务端部署在云服务器时的数据库地址：`127.0.0.1:5432`
- 数据库名：`unknown_platform`
- 数据库账号：`unknown_app`
- 数据库密码：通过本地 `server/apps/.env.prod.local` 或环境变量提供，不写入代码仓库

## 本地真实联调流程

Windows PowerShell 先启动 SSH 隧道：

```powershell
ssh -i C:\Users\Administrator\.ssh\id_rsa -N -L 15432:127.0.0.1:5432 root@8.153.110.192
```

再启动后端：

```powershell
cd D:\code\un-know\server\apps
Get-Content -LiteralPath .env.prod.local -ErrorAction SilentlyContinue | ForEach-Object {
  $line = $_.Trim()
  if ($line -and -not $line.StartsWith("#")) {
    $name, $value = $line -split "=", 2
    if ($name -and $null -ne $value) {
      Set-Item -Path "Env:$name" -Value $value
    }
  }
}
mvn.cmd spring-boot:run
```

macOS/Linux：

```bash
cd /Users/bigfu/code/un-know
./scripts/dev/app-server.sh
```

macOS/Linux 下 `app-server.sh` 会自动检查 `127.0.0.1:15432` 并在未监听时使用 `~/.ssh/unknow/bigfu.m2pro.mac.home.pem` 拉起 SSH 隧道。可以把数据库连接配置放入本地忽略文件 `server/apps/.env.prod.local`，启动脚本会自动加载；也可以通过当前终端环境变量传入。需要改 SSH 密钥时设置 `APP_SERVER_TUNNEL_KEY`，需要跳过隧道时设置 `APP_SERVER_TUNNEL_ENABLED=0`。
`app-server.sh` 启动前还会检查 `127.0.0.1:9988`；已有监听时直接提示并跳过启动。

## 云服务器数据库状态

云服务器已安装 PostgreSQL，并创建：

```sql
CREATE DATABASE unknown_platform;
CREATE USER unknown_app WITH PASSWORD '由环境变量保存';
```

当前推荐本地开发继续走 SSH 隧道。公网直连 `8.153.110.192:5432` 需要额外放行阿里云 ECS 安全组、本机公网 IP、PostgreSQL 监听地址与 `pg_hba.conf`，第一阶段不建议直接暴露数据库端口。

## 数据库版本管理

项目使用 Flyway 管理数据库结构：

```text
server/apps/src/main/resources/db/migration
```

当前迁移：

```text
V1__init_platform_schema.sql
V2__real_client_data.sql
```

后端启动 `prod` profile 时会自动校验并执行未应用的迁移脚本。
