## 当前规划原则

1. 注册时选择学生、商户或教育服务家长身份；登录时只输入手机号和验证码，由系统识别账号身份。普通用户身份互斥，同一账号不允许同时拥有多个身份。
2. 学生注册完成后先进入信息补充中转页，可跳过；初步补充宿舍楼栋和楼层。教育服务家长注册完成后先进入孩子信息补充中转页，可跳过；初步补充孩子年级和科目，后续发布家教需求时强校验。
3. 学生核心功能：提交回收、购买闲置、加入兼职、发布校园服务需求。
4. 商户核心功能：发布商品、发布中长期兼职，也可以发布短期事情维度兼职；商户需要认证审核通过后才能发布。教育服务家长核心功能：发布家教需求、查看报名并对接优秀大学生家教。
5. 学生端主页面收敛为优选和兼职两个内容区；右侧/角落保留用户头像悬浮入口，展开后提供狩猎、发布、余额、更多。
6. 优选是内容聚合入口，内容来源包含平台自营和商户端审核后的商品或服务；兼职是可报名的兼职内容入口。
7. 学生购买优选商品/服务时，系统按产品信息提供物流、立刻配送、指定时间等履约方式；最终金额由产品金额、服务费、物流费等合计，选择付款方式后提交支付。
8. 学生存在流转中订单时，首页头像左侧展示订单快捷按钮，点击进入订单详情，可查看状态和联系电话，并进行取消、改约等操作；支付异常时通过我的快捷入口增加红色异常特效，引导学生确认支付情况。
9. 优选订单送达/完成后不支持直接退款；平台自营产品由平台人工接入售后，后续入驻商户产品由商家自行售后处理，平台围绕投诉情况进行人工复核并记录信用分影响；退款发起后实时到账，最晚 2 个工作日。
10. 企业/商户发布的兼职以中长期兼职为主；学生报名时按发布方配置填写报名表，发布方在发布管理详情中筛选并确认。
11. 兼职发布需要填写结算日期和人员要求表单，人员要求支持“无要求”和“限性别”等快捷按钮。
12. 兼职发布可配置是否允许超额报名：不超额时报名满自动结束；允许超额时由发布方在报名人员中手动确认最终人员。
13. 兼职金额统一从平台流转：发布方发布时先支付到平台，完成后确认结束，再由平台结算至每个报名成员账户。
14. 发布方筛选确认报名成功名单后，系统将报名成功人员在报名时填写的字段通过邮件发送给发布方，后续由发布方直接对接；身份证信息不随邮件发送，仅保留必要的脱敏或验证状态。
15. 项目完成时，发布方通过“我的发布”进入发布详情进行项目完成确认；项目结束时间后一周内未确认的，系统自动完成项目结束确认。
16. 项目结束后系统开始给每位参与者结算费用；发布方和参与者都可通过“我的 - 兼职”进行评价或举报。
17. 被确认的报名者未签到、发布方确认后未聘用等异常行为，会影响信用分并可能扣减押金；兼职模块的支付异常、退款、争议复核及信用分/押金处理与优选下单保持一致。
18. 校园服务模块分为发布和领取两个子模块，承接原“学生校园服务需求”能力；学生发布的当日即送、预约代购等需求进入发布子模块，可接单内容实时进入狩猎池，由领取子模块承接接受委托、报价委托、履约和结算。发布时可选押金发布或委托发布。押金发布为商品价格 + 服务费合计支付并发布，领取者已购买后费用不再普通退回，争议需平台人工介入；委托发布为先支付服务费，商品实际费用由领取者输入金额，发布者确认并支付后，领取者完成购买和送达。
19. 校园服务送达后，由发布者确认服务结束；双方可通过“我的 - 服务”进行评价。已结束服务开始金额结算，费用先进入观察期，观察期过后进入钱包可提现。
20. 学生端主页面头像悬浮菜单中的“狩猎”用于切换服务方上线状态，实时接收狩猎任务消息；狩猎池内任务先到先得，系统也可定向分配给在线狩猎成员；接受委托立即锁单，报价委托需发布者确认后锁单，报价确认期间仍可被他人接受；可选狩猎时间，不选默认次日 0 点关闭。
21. 学生开启狩猎前需要先完成学生认证，再完成狩猎二次验证：身份证实名信息 + 学籍信息，并缴纳 100 元押金；通过后获得初始 10 信用分。
22. 狩猎信用分影响可接单额度；信用分具体档位、增减规则和影响范围后续单独补充专项机制，当前文档只记录方向。
23. 客户端右上角提供平台管理人员登录入口，核心处理审核、对接和复核。
24. 暂不开放学生自由买卖市场，商品发布和展示需要平台审核与对接。
25. 自营产品以大学生常用耗材为前提，由平台自行采购、自营备货，主打低决策、高频复购的引流内容。
26. 管理端维护校园信息，包括学校、校区、楼栋、楼层、活动区域和位置块；发布信息时优先从管理端区域列表选择，也支持自定义填写。
27. 学生端“我的账户”区分可提现钱包和保护期/观察期账户；任务收入先进入保护期/观察期，期间不可立即提现。
28. 所有角色均可对内容、商品、服务、订单、兼职和对接过程提交举报；举报审核确认违规后，违规账号进入冻结状态，不可使用服务。
29. 冻结账号登录后默认跳转解冻申请页，仅可查看处理结果、申诉、缴纳违约金或赔偿，不可使用产品服务能力。
30. 冻结账号可按平台处理结果缴纳违约金或赔偿后申请解冻；解冻后仍进入 1 个月监管期。监管期内无法买卖、狩猎或提现；禁言状态无法发布或狩猎；封禁状态无法登录。
31. 优选、兼职和校园服务详情页统一展示标题、详情、发布时间、紧急程度、产品准确型号、零售价、备注和地点。
32. 文档持续更新，优先保证方向清楚、范围可控、阶段可落地。
