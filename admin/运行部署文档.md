## 3. 初始化后本地运行

正式工程初始化后，建议命令如下：

```powershell
cd D:\code\un-know\admin\app
npm install
npm run dev
```

建议默认端口：

```text
http://127.0.0.1:5175
```

建议环境变量：

```powershell
$env:VITE_ADMIN_API_BASE_URL="http://127.0.0.1:8080"
$env:VITE_APP_ENV="local"
```

## 5. 构建部署

生产构建：

```powershell
cd D:\code\un-know\admin\app
$env:VITE_ADMIN_API_BASE_URL="https://api.example.com"
npm ci
npm run build
```

构建产物：

```text
admin/app/dist
```

部署方式：

1. 将 `dist` 上传到 Nginx 或静态站点。
2. 配置后台域名，例如 `https://admin.example.com`。
3. 后端只允许管理端域名访问管理接口。
4. 管理端登录态必须校验平台管理角色权限。

Nginx 示例：

```nginx
server {
  listen 80;
  server_name admin.example.com;

  root /var/www/unknown-admin;
  index index.html;

  location / {
    try_files $uri $uri/ /index.html;
  }

  location /assets/ {
    expires 30d;
    add_header Cache-Control "public, immutable";
  }
}
```

## 7. 部署检查清单

- 管理端页面可打开
- 刷新任意路由不会 404
- 未登录访问自动跳转登录页
- 非平台管理角色无法进入管理端
- `/api/admin/health` 可访问
- 管理端页面只展示真实接口返回的数据
- 高风险操作有二次确认和审计记录
